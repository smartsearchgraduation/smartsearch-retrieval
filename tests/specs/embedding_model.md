# Embedding Model — Test Specification

**Component:** `models/` package — three model pools (`CLIPModelPool`, `DINOv3ModelPool`, `OpenCLIPModelPool`), three managers (`TextModelManager`, `VisualModelManager`, `FusedModelManager`), and per-backend embedders (CLIP / BGE / Marqo / Qwen / DINOv3) for text, image, and fused modalities.
**Source files:** `models/clip_model_pool.py`, `models/dinov3_model_pool.py`, `models/open_clip_model_pool.py`, `models/textual_models/{text_model_manager,clip_text_embedder,bge_base_embedder,marqo_text_embedder,qwen_8b_model}.py`, `models/visual_models/{visual_model_manager,clip_image_embedder,dinov3_image_embedder,marqo_image_embedder}.py`, `models/fused_models/{fused_model_manager,clip_fused_embedder,marqo_fused_embedder}.py`.
**ID prefix:** `RU-EM-NN`, sequential, zero-padded, no gaps.
**Fixtures:** `tmp_image_path` (a real on-disk RGB JPEG/PNG for image embedders), `monkeypatch`, `tmp_path`. Every test must call `CLIPModelPool.clear()` / `DINOv3ModelPool.clear()` / `OpenCLIPModelPool.clear()` in setup or teardown to avoid cross-test pollution.
**Mocking notes:** No real model weights are ever loaded. Pool tests inject fake `clip` / `open_clip` / `transformers` modules into `sys.modules` BEFORE the pool's `.get(...)` call so the inner `import` resolves to the stub. Embedder tests patch `CLIPModelPool.get` / `DINOv3ModelPool.get` / `OpenCLIPModelPool.get` via `monkeypatch.setattr` AFTER importing the embedder module, returning stub model objects whose `encode_text` / `encode_image` / `__call__` methods return deterministic torch tensors of the documented dimension (CLIP=512, BGE=1024, Marqo=1024, Qwen=4096, DINOv3=4096), L2-normalized. BGE and Qwen embedders bypass the pools and directly load via `transformers.AutoTokenizer.from_pretrained` and `AutoModel.from_pretrained` — patch those at the module level. NEVER mock `faiss.*` (not relevant here). Use `tests._helpers.deterministic_vector(seed, dim)` cast to a torch tensor where helpful.
