# FAISSManager — Test Specification

Source under test: `vector_db/faiss_manager.py` (single module containing `IndexType` enum, `sanitize_model_name`, `make_folder_name`, and `FAISSManager` class). ID prefix: `RU-FM-NN` (zero-padded, sequential, never reused). Tests use the real in-memory faiss library — `faiss.*` and `FAISSManager` MUST NOT be mocked. Persistence paths come exclusively from the `tmp_index_dir` fixture (a `tempfile.TemporaryDirectory`). Embedding inputs are produced by the deterministic helpers `vec_factory`, `clip_vec`, `bge_vec`, `marqo_vec`, `qwen_vec`, `dinov3_vec`, and managers are constructed via `faiss_manager_factory`. No real model weights are loaded anywhere.
